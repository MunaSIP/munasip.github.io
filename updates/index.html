LATEST RELEASE

MunaSIP 1.7.5

Released 21 October 2026 · Linux / AMD64 · MIT

Official release notes

A voicemail inbox for every extension.

See who called, play the message, mark it read and delete it from the employee portal.

The caller ID your provider expects.

Set the outbound phone number independently of the SIP username used to register your trunk.

Ready means the PBX is ready.

The health endpoint waits for PostgreSQL, Asterisk and the dialplan before reporting the system healthy.

Move to the published image.

Back up your persistent data, pull the pinned tag and recreate the container with the same volume and configuration. The project notes that the v1.7.4 image did not publish; use v1.7.5.
