Aramanın bütününün haritası

Düğümleri tuvale sürükleyin ve her çıkışı sonraki adıma bağlayın. Akışlar JSON olarak saklanır ve API’nin ARI motoru tarafından çalıştırılır. Taslak, canlı aramaların kullandığı yayımlanmış sürümden ayrıdır.

Canlı bir API bağlayın

API isteği düğümü GET, POST, PUT, PATCH ve DELETE’i, şablonlu adres/başlık/gövdeleri ve JSON yollarıyla yanıt eşlemeyi destekler. Kimlik doğrulama Bearer, Basic veya özel bir başlık olabilir. Kimlik bilgilerini akış JSON’unda değil, Ayarlar → Sırlar’da tutun.

Varsayılan zaman aşımı 3 saniye, üst sınır 10 saniyedir; isteğe bağlı tek yeniden deneme vardır. Zaman aşımları, başarısız yanıtlar ve ayrıştırılamayan veri hata çıkışını izler. Bu çıkış bağlı değilken akış yayımlanamaz.

API düğümü eşlemesi
# API isteği düğümündeki kavramsal eşleme
# Yanıt: {"customer": true, "agent": "201"}
$.customer  -> known_customer
$.agent     -> agent
 
# Sonraki: koşul -> eşlenen temsilciye aktar
# Hata: genel destek kuyruğuna yönlendir

Hatta doğru sözcükleri koyun

Konuşma ve API şablonlarında $name veya {{name}} kullanın. Süzgeçler değerleri biçimlendirir; digits, round, amount, province ve ascii dahildir. Anonslar cümle cümle sentezlenir ve önbelleğe alınır.

Çevrimdışı İngilizce sentez sağlanmaz. Edge konuşması, sentez isteklerini dış bir servise gönderir. Motorları ve anons içeriğini kendi gizlilik gereksinimlerinize göre seçin.

Deneyin, yayınlayın, geri alın

  1. Eksik hedefleri, bağlı olmayan çıkışları, ulaşılamayan düğümleri ve alt akışlar dahil döngüleri doğrulayın.
  2. Arayan, DID, tarih/saat ve tuş takımı girişlerini simüle edin. Değişkenleri ve ziyaret edilen adımları inceleyin. Sahte API JSON’u veya gerçek bir test ucunu bilinçli kullanın.
  3. Gözden geçirilmiş taslağı yayınlayın. Süren aramalar başladıkları sürümde biter.
  4. Geri alma için sürüm geçmişini tutun ve kendi kayıtlarınız için JSON dışa aktarın.

Simülasyon mantığı incelemeye yardım eder. İş aramalarını yeni bir akışa yönlendirmeden önce gerçek ortamı, zamanlamaları ve operatör rotalarını kendi santralinizde deneyin.
