Hazır imajı çekin.

v1.7.5 çalışan sesli mesaj kutusunu, operatör arayan kimliğini ve santral hazır olma kontrollerini ekler. Yenilikleri okuyun →

Linux x86-64 Docker sunucusu için önerilen başlangıç. Sürüm etiketini sabitleyin, /data yolunu kalıcı tutun ve HTTPS ile ortam ağını ayarlayın.

MunaSIP kurulumu
docker run -d --name munasip \
  --restart unless-stopped \
  -p 3000:3000 \
  -p 10000-10100:10000-10100/udp \
  -v munasip-data:/data \
  -e EXTERNAL_IP=203.0.113.10 \
  -e PUBLIC_HOST=pbx.example.com \
  ghcr.io/munasip/munasip:1.7.5

Çalıştırmadan önce örnek IP ve alan adını değiştirin. Bu komut uygulama portu 3000’i ve RTP ortamını açar; herkese açık bir HTTPS vekili kullanın. Operatörünüzü bağlamadan önce rehberi okuyun.

Kurulum rehberini izleyin

Küçük bir ofis. Doğru bir sunucu.

Platform
Linux x86-64. Debian 12/13 veya Ubuntu 22.04+ önerilir.
Çalışma ortamı
Docker Engine; çok servisli kurulum için Compose v2.
Kaynaklar
2–4 vCPU, 4–8 GB RAM. Nöral konuşma santral işlemcisini kullanır.
Veri
Kalıcı depolama ve denenmiş bir yedek planı.
Ağ
Herkese açık alan adı, HTTPS/WSS, erişilebilir RTP veya ayarlı TURN.

Kaynaktan başlayın.

v1.7.5 kaynak arşivini indirin ya da depoyu klonlayıp sürüm etiketine geçin. Yığının tamamını Docker Compose ile derleyin.

Kaynak ZIP’ini indir
Compose ile derleyin
Kaynak kurulum komutlarını göster
Sürüm kaynağından derleyin
git clone https://github.com/MunaSIP/MunaSIP.git
cd MunaSIP
git checkout v1.7.5
cp .env.example .env
chmod +x scripts/gen-certs.sh
./scripts/gen-certs.sh
docker compose up --build -d

İmajda ne olduğunu bilin.

Asterisk, API, web paneli, gömülü PostgreSQL ve konuşma motorları. Yayımlanan imaj linux/amd64 içindir. Bu sürüm yerel Windows/macOS kurucuları ve ARM imajları yayımlamaz.
